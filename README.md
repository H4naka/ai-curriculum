# AI Engineering — Self-Study Curriculum

It's a self-paced, structured curriculum for learning AI and ML engineering from the ground up. Built as a single-page web app with progress tracking that syncs across devices.
The curriculum is made using generative AI and asumes an engineering background. Its main purpose is to give a structured learning/refreshing plan to follow.

## What’s inside

A handcrafted learning path covering the full AI engineering stack, from Python fundamentals and statistics through to model deployment and production ML systems. Each module contains lessons, mini exercises, and deep-dive projects.

Progress is saved to your account and syncs across your laptop, phone, and any other device automatically.

## Stack

- **Frontend** — Vanilla HTML/CSS/JS, no framework
- **Hosting** — GitHub Pages
- **Auth & Database** — Supabase (GitHub OAuth + Postgres)

## Live app

[h4naka.github.io/ai-curriculum](https://h4naka.github.io/ai-curriculum)

Sign in with your GitHub account to track your progress across devices.

## Local development

No build step needed. Just open `index.html` in a browser — it works offline with localStorage as a fallback when not signed in.
